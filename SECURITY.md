# Security

This policy covers all takwerx projects. A repository with its own SECURITY.md follows that file instead.

## Reporting a security problem

Do not report vulnerabilities, CVEs, exploits, leaked keys or passwords in
public issues, discussions or pull requests. Email **takwerx@gmail.com**
instead. Include what is affected, the version, and how to reproduce it. If you
have a fix, attach or describe it.

## Supported versions

Only the latest release gets security fixes. Update before reporting.

## What to expect

We reply within 3 working days, work with you privately until a fix ships, and
credit you if you want.

Please do not disclose it publicly until a fix is released.

## Scope

Code in takwerx repositories: the installers, the console and its modules, the
ATAK and CloudTAK plugins, and the scripts and websites we publish. Bugs in
upstream projects (TAK Server, ATAK, CloudTAK, Authentik, Caddy, MediaMTX and
others) belong with those projects. If you are not sure, email us and we will
point you to the right place.
